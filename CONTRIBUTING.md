At the moment I'm not looking for major source code contributions. If you encounter a minor bug and decide to fix yourself, then feel free to open a PR and I will take a look.  
Please always get in touch first before you spend too much time working on things, as I can't gurantee that I will accept your PR otherwise. The best way to get in touch is to open an issue or via Discord (@thetxt).  
The main development work happens in the dev branch, so please open PRs with dev as the base.  
dev then gets merged into main for every release, so that main always contains the latest published release.

The best way for you to help is to spread the word about this project and to test it yourself. If you encounter any bugs or have ideas for things that could be improved, then please open an issue or get in touch otherwise.

The last option is to [support me financially](https://buymeacoffee.com/thetxt), which would make it possible for me to invest more time into Oxide. Please only do this if you can afford it.
